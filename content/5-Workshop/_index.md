# Detailed Guide: Building a Real-time Bidirectional Translation Web App on AWS

#### Workshop Overview

Build a real-time bilingual conversation translation web system that allows two users to communicate in different languages. This section outlines the steps to prepare the AWS infrastructure for the system. The system utilizes AWS to provide the backend runtime environment, API communication, and AI services for Speech-to-Text and Translation.
