# Hướng dẫn chi tiết Xây dựng Real-time Bidirectional Translation Web trên AWS

#### Tổng quan bài Thực hành (Workshop)


Xây dựng một hệ thống web dịch hội thoại song ngữ theo thời gian thực, cho phép hai người dùng giao tiếp bằng hai ngôn ngữ khác nhau. Mục này trình bày các bước chuẩn bị hạ tầng AWS cho hệ thống phiên dịch hội thoại song ngữ theo thời gian thực. Hệ thống sử dụng AWS để cung cấp môi trường chạy Backend, giao tiếp API và các dịch vụ AI phục vụ Speech-to-Text và Translation..
